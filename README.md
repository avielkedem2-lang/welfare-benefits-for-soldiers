"# welfare-benefits-for-soldiers" 


מבנה קבצים:




כל האנדפויטים:


1. POST/soldiers/:soldierId/benefits => האנדפויט הזה מקבל אובייקט ןהמערכת בודקת אם הכל תקין במידה וכן המערכת מכניסה db ומחזירה למשתמש status 201 ומחזירה רשומת הטבה.
במידה ולא הכל היה תקין למשל כבר קיימית רשומת הטבה עם אותו id המערכת מחזירה למשתמש status 409 
ואומרת לו שכבר קיים כזאת רשומה.

הסבר לבחירת בסיס נתונים לכל ישות:

1. welfare_record => אני בחרתי בבסיס נתונים של mongodb כי זה לא רלציוני ועם לא רלציונני אנחנו מתעסקים עם אובייקטים ורשימות


2. budget_allocation => אני בחרתי בבסיס נתונים של spuabase מכיוון שזה רלציוני,
ובגלל הקישור של furnkey.



3. spend_transaction => אני בחרתי בבסיס מבנה נתונים של supabase כי זה רלציוני,
ובגלל הקישור של furnkey.
